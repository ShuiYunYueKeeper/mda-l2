## 一、通用交互原则

1. **有选区时**
   - 字符格式类操作：作用于选中的文字。
   - 段落格式类操作：作用于选区覆盖的所有段落。

2. **无选区时**
   - 字符格式类操作：只改变“后续输入格式”，不修改已有文本。
   - 段落格式类操作：作用于当前光标所在段落。

3. **按钮状态**
   - 支持：禁用、未激活、激活、半激活/混合态。
   - 当选区包含混合格式时，不要误显示为单一格式，建议显示半激活或“混合”。
   - **新打开文档且尚未点进编辑区时**：特殊功能（撤销/重做/清除格式）、字符格式类、段落格式类按钮一律置灰；点进编辑区（或表格格内等可编辑区）后恢复按常规规则启用。保存/查找/批注/复制预览/导出/插入等不依赖插入点的入口保持可用。失焦点工具栏不回退为置灰。
   - **选中分割线块时**：同上，特殊功能、字符格式类、段落格式类一律置灰（分割线无可编辑字符/段落格式）。
   - tip 中「空格」指 Markdown **语法里的空格字符**（如 `1. `、`- `），**不是**空白行。

4. **hover编辑栏工具**
   * tip首行显示功能+快捷键
   * 第二行显示功能说明（如有）

5. **只读模式**
   - 所有编辑类按钮都应禁用。

# 二、特殊功能

## 1. 撤销 / 重做

### 撤销

| 项目 | 规则 |
| --- | --- |
| 无修改时 | 撤销按钮置灰 |
| 有可撤销修改时 | 按钮可用 |
| 点击后 | 撤销最近一次文档修改 |
| 撤销到初始状态后 | 撤销按钮再次置灰，文档无标脏 |
| 快捷键 | `Ctrl + Z` |

### 重做

| 项目 | 规则 |
| --- | --- |
| 无重做历史时 | 重做按钮置灰 |
| 有可重做操作时 | 按钮可用 |
| 点击后 | 重做最近一次被撤销的操作 |
| 快捷键 | `Ctrl + Y` |

### 开发注意

- 所有修改文档的操作都应进入撤销栈。
- 仅改变 UI 状态的操作，例如打开颜色面板、进入格式刷模式，不应进入撤销栈。

---

## 2. 格式刷

格式刷用于复制源文本的字符格式和段落格式，并应用到目标文本。

### 源格式采集

| 状态 | 行为 |
|---|---|
| 有选区 | 复制选区起始位置的字符格式和段落格式 |
| 无选区 | 从当前光标所在位置采集字符格式和段落格式 |
| 光标在空段落 | 采集该段落的默认格式 |

### 点击格式刷后

- 按钮进入激活状态。
- 鼠标指针应变为格式刷样式。
- 单击格式刷：应用一次后自动退出格式刷模式。
- 双击格式刷：锁定格式刷模式，可连续应用多次。
- 再次点击格式刷按钮或按 `Esc`：退出格式刷模式。

### 应用格式

| 应用方式 | 行为 |
|---|---|
| 拖选目标文本 | 应用字符格式，并将段落格式应用到目标文本所在段落 |
| 只点击目标段落空白处，不拖选 | 只应用段落格式，不修改该段已有字符格式 |
| 无目标选区时 | 不修改已有内容 |

### 按钮状态

- 正常状态下可用。
- 格式刷模式中按钮激活。
- 如果产品要求必须先选中源文本，则无选区时格式刷可置灰。

---

## 3. 清除格式

### 有选区时

点击清除格式：

- 清除选中文字的字符格式：
  - 加粗
  - 斜体
  - 下划线
  - 删除线
  - 字体颜色
  - 行内代码
  - 其他字符样式
- 将选中内容涉及的段落格式恢复为默认：
  - 标题恢复为正文
  - 移除有序/无序/任务列表
  - 对齐恢复为默认左对齐
  - 清除段落缩进和列表层级

### 无选区时

- 只清除“待输入字符格式”，不修改已有文本。
- 例如刚点击了加粗但还没输入文字，点击清除格式后，后续输入不再加粗。
- 如果你的产品希望清除格式也作用于当前段落，则无选区时可重置当前段落为正文，并清除该段落级格式。

### 按钮状态

| 场景 | 按钮状态 |
| --- | --- |
| 有选区 | 可用 |
| 无选区，但有待输入格式 | 可用 |
| 无选区，且无待输入格式 | 置灰 |

# 三、字符格式类

适用于：加粗、斜体、下划线、删除线、字体颜色、行内代码。

## 通用规则
​
### 有选区时

- 如果选区中所有文字都已具有该格式：
  - 按钮激活。
  - 点击后取消该格式。
- 如果选区中只有部分文字具有该格式：
  - 按钮显示半激活/混合态。
  - 点击后对整个选区应用该格式。
- 如果选区中所有文字都没有该格式：
  - 按钮未激活。
  - 点击后应用该格式。

### 无选区时

- 点击按钮切换“后续输入格式”。
- 不修改已有文本。
- 按钮状态反映当前待输入格式或光标所在位置的格式。

示例：

> 无选区时点击加粗，按钮激活，开始输入文字，新文字为加粗。
> 已有文字不会被加粗。

## 9. 行内代码

行内代码是字符级格式，不要与代码块混淆。

| 项目 | 规则 |
|---|---|
| 类型 | 字符格式 |
| 有选区 | 全选行内代码则取消，否则应用行内代码 |
| 无选区 | 切换后续输入行内代码状态 |
| 快捷键 | `Ctrl + Shift + C` |
| Markdown | `` `文本` `` |
| 可撤销 | 是 |

### 与代码块的关系

- 代码块是块级元素。
- 行内代码用于段落中的短代码片段。
- 如果当前光标位于代码块内，行内代码按钮应置灰。
- 如果选区包含代码块内容，行内代码按钮应置灰。
- 如果代码块是纯代码块，则字符格式类按钮在代码块内通常都应禁用。

# 四、段落格式类

适用于：标题/正文、对齐、有序/无序/任务列表、增加/减少缩进。

## 通用规则

### 有选区时

- 作用于选区覆盖的所有段落。
- 如果选区跨多个不同段落格式，按钮置灰。

### 无选区时

- 作用于当前光标所在段落。
- 不会只影响后续输入，而是直接修改当前段落。

---

## 10. 标题 / 正文

通常表现为段落样式下拉框或按钮组。

### 无选区时

- 下拉框显示当前光标所在段落的样式。
- 选择新样式后，立即应用到当前段落。

### 有选区时

- 下拉框显示选区段落的统一样式。
- 如果选区包含多个不同样式，显示“混合”或空。
- 选择新样式后，应用到选区覆盖的所有段落。

### 交互细节

- 选中文字时点击标题，改变的是一整段，而不是只改变选中的文字。
- 如果当前样式是“正文”，正文按钮或菜单项应激活。
- 如果当前样式是“标题 1”，标题 1 菜单项应激活。

### 可撤销

是。

## 11. 对齐：左对齐 / 居中 / 右对齐

> **工具栏入口已删除**（Markdown 无原生对齐，**MD-N/A**）。以下保留设计说明备查。

这些是对齐按钮组，属于段落格式。

### 无选区时

- 当前段落的对齐方式对应的按钮应激活。
- 点击其他对齐按钮后，当前段落切换为对应对齐方式。

### 有选区时

- 作用于选区覆盖的所有段落。
- 如果所有段落对齐一致，对应按钮激活。
- 如果选区段落对齐方式不同，按钮组不高亮或显示混合态。
- 点击某个对齐按钮后，所有选区段落统一为该对齐方式。

### 按钮状态

| 当前段对齐 | 按钮状态 |
|---|---|
| 左对齐 | 左对齐按钮激活 |
| 居中 | 居中按钮激活 |
| 右对齐 | 右对齐按钮激活 |
| 混合选区 | 不高亮或半激活 |

### 可撤销

是。

## 12. 无序列表 / 有序列表 / 任务列表

这三个列表类型通常互斥。

### 无选区时

- 当前段落如果已经是该列表类型：
  - 按钮激活。
  - 再次点击该按钮，取消列表，恢复正文。
- 当前段落如果不是该列表类型：
  - 点击后转换为该列表类型。
- 如果当前是有序列表，点击无序列表：
  - 从有序列表切换为无序列表。

### 有选区时

- 作用于选区覆盖的所有段落。
- 如果所有选中段落已经是该列表类型：
  - 按钮激活。
  - 点击后取消列表。
- 如果部分或全部段落不是该列表类型：
  - 点击后统一转换为该列表类型。

### 不改变原有样式

- 切换列表**只增删行首的列表标记**，不动段落级与字符级样式。
- 原本是标题的行，加上无序/有序列表后**仍是标题**：`## 标题` → `- ## 标题`。
  - CommonMark 允许列表项内嵌 ATX 标题，渲染、大纲、块手柄均按标题处理。
  - 取消列表后标题原样回来：`- ## 标题` → `## 标题`。
- 加粗、斜体、行内代码等字符格式一律保留。

### 任务列表特殊行为

- 任务列表项前显示复选框。
- 点击复选框只切换任务完成状态。
- 点击复选框不应进入文字编辑态，但应产生撤销记录。
- 任务列表与有序/无序列表互斥。
- 任务列表项可以嵌套，通过增加缩进实现子任务。
- **标题行上任务列表按钮置灰**：GFM 规定任务标记后的首个块必须是段落，
  `- [ ] ## 标题` 中的 `##` 会退化为字面文本，无法既是任务项又是标题。
  与「加粗在标题行置灰」同理，宁可置灰也不静默丢掉标题。
  需要转任务项时，先用段落下拉把标题改为正文。

### 列表按钮状态

| 当前段列表类型 | 按钮状态 |
|---|---|
| 有序列表 | 有序列表按钮激活 |
| 无序列表 | 无序列表按钮激活 |
| 任务列表 | 任务列表按钮激活 |
| 普通正文 | 所有列表按钮未激活 |
| 选区混合列表类型 | 不高亮或半激活 |
| 标题行（含 `- ## 标题`） | 无序/有序可用，任务列表置灰 |

### 可撤销

是。

# 六、开发建议

1. **字符格式按钮不要影响已有文本**
   无选区时，点击加粗、斜体、下划线等只改变输入状态。

2. **段落格式按钮要影响当前段**
   无选区时，点击标题、列表、对齐、缩进等应直接修改当前段落。

3. **混合状态要明确**
   不要让按钮在混合选区时错误显示为激活或未激活，建议实现三态。

4. **代码块内要限制格式**
   行内代码、列表、标题、对齐、缩进等格式在代码块内通常应禁用。

5. **所有修改可撤销**
   包括格式刷应用、清除格式、列表切换、缩进调整等，都要进入撤销栈。

6. **只读模式统一禁用**
   只读模式下，所有编辑类按钮都应置灰。
