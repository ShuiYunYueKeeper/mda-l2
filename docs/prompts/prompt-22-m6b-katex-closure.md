完成 `docs/M6b-acceptance-checklist.md` 中延后的 M6b-2（公式预览清晰度）与 M6b-5（复制预览公式转图片且不闪烁），M7 继续待续。

## 审查结论

- KaTeX 0.17、同版本 CSS/字体和安全插件链已在上一轮对齐；预览缺少专项排版。
- 公式 `foreignObject` 离屏栅格化已存在，但被功能开关关闭，且仅生成 1×、块级公式按整行采样。
- 无需新增 IPC；公式复制应继续使用 detached 克隆 + 离屏 canvas，禁止触碰视口 DOM。

## 实施摘要

1. 预览：行内公式基线/字号/抗锯齿微调；块级公式改为紧凑居中卡片，超宽内容可横向滚动。
2. 复制：启用公式转 PNG；按内部 `.katex` 本体采样，锁定预览 computed 字号，2× 栅格化并保留逻辑显示尺寸。
3. 降级：字体内联不完整即抛错，单公式回退 TeX/`[公式]`，不阻断整篇复制。
4. 测试：新增 KaTeX 行内/块级/围栏/安全渲染，以及 SVG payload 的 2× 尺寸、foreignObject、style 转义测试。
5. 文档：同步验收清单、帮助、README、quality、few-shot 与截图清单。

实机首轮发现：导出仅加载 KaTeX 默认 `1.21em`，但测量框来自预览覆盖后的 `1.05em`，加上内部固定宽高裁切，导致长公式/分式显示不全。修复为导出 clone 使用预览 computed font-size/line-height、取 rect/offset/scroll 最大值并移除内部 `overflow:hidden`。

实机复验发现：KaTeX 的分式、上下标等视觉内容可能超出外层布局盒，按外层宽高栅格化会裁切；行内公式沿用块级留白又会在表格中造成换行和行高膨胀。期间尝试 Blob URL，但 Chromium 将含 `foreignObject` 的 Blob SVG 画入 canvas 判为跨源污染，导致全部公式回退为 TeX，故撤回。最终改为 UTF-8 Base64 data URL，测量 `.katex-html` 全部可见子节点边界并补偿偏移；行内/块级分别使用 4×4px、16×12px 留白，复制表格不再强制铺满容器。

最终实机收敛：含公式的表格改为整表 2× PNG，完整保留单元格内多个公式、分隔符、行高和列宽；整表失败才回退逐公式导出。单公式或整表若 2× canvas 创建失败，仅失败项重试 1×，避免整篇出现原始 TeX，同时不改变其逻辑显示尺寸。
