## 用户目标

Free 门禁后基础体验迭代（公式延后）：全屏双拷贝、侧栏/大纲可读性与折叠、预览调图 + 设置默认缩放。

## 关键结论

- 默认缩放必须是「自动固有宽 × 系数」，不能压成预览栏绝对宽。
- 设置弹窗须先锁菜单；构建失败要解锁，避免菜单永久无响应。
- 拖动调宽时勿全局亮蓝角标；双击还原当前设置比例。

## 动作摘要

1. M6b-1：全屏「复制图片」「复制源码」（围栏）；Ctrl+C 默认图片。
2. M6b-3：文件树/大纲字号行距、收起钮、子标题折叠。
3. M6b-4：预览拖拽调宽；设置 `auto/25/50/75`；复制预览跟尺寸；双击还原。
4. 文档：`M6b-acceptance-checklist.md`、AGENTS §4e3、quality、few-shot §21。
