# Markdown工作台隐私说明

本说明适用于 Markdown工作台（MDA）桌面应用。联系邮箱：mda.markdown@gmail.com。

## 文档留在本机

你打开和编辑的 Markdown 文件、批注、粘贴进文档的图片，都保存在你自己的电脑上。本应用不提供账号，也不把这些文件上传到开发者的服务器。

## 不强制注册

使用本应用不需要注册、登录或绑定手机号。

## AI 密钥

AI 功能需要你自行填写服务地址和 API 密钥。密钥使用操作系统提供的加密方式保存在本机。请求从本机直接发往你填写的服务地址，不经过 Markdown工作台的服务器。未填写密钥时，不会代你发出 AI 请求。

## 激活码

Pro 激活码在本机校验。校验不需要联网，也不会把激活码发到开发者的服务器。

## 检查更新

只有在你主动检查更新时，应用才会连接 GitHub 上的发布页，查看是否有新版本。不会在后台收集使用记录。

## English

Markdown Workbench (MDA) keeps your documents, notes, and pasted images on your computer. There is no account and no upload of those files to the developer. AI API keys stay on the device and requests go only to the service address you enter. License keys are checked on the device. The app contacts GitHub only when you choose to check for updates.
