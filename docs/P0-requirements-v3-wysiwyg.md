### 写回语义：D3 / F10-7 / AC-10 在不同技术路线下的含义

| 概念 | 路线甲：源码即真源（**P1 已选**，方案 A） | 路线乙：富结构模型 + 序列化（方案 B/C） |
|------|------------------------------------------|----------------------------------------|
| 文档模型 | Markdown 文本（`EditorState.doc`） | 富结构 doc（ProseMirror 等） |
| 保存路径 | `doc.toString()` → `writeRawFile` | `serialize(doc)` → `writeRawFile` |
| F10-7「序列化」 | **不适用**；以「往返保真」代替（AC-10） | 必须实现，稳定、幂等、可预测 |
| D3「仅改动块局部重写」 | **退化为** transaction 局部文本修改；改一字磁盘差一字；AC-7 / AC-18 即验收口径 | 被编辑块映射回源码行范围后局部替换 |
| A18 块行映射 | **非日常写回依赖**；`token.map` POC 仅作批注安全与批量操作（如格式化整篇）的辅助证据 | **P1 硬前提**；POC 失败须走路径 B 退路或停止 |
| P2 禁止项 | 块映射写回层、独立序列化引擎、为 AC-18 单独实现 diff 算法 | — |

## 背景与目标

### 背景

MDA 2.0（Phase A Free）已交付：文件管理、源码编辑栏（textarea + 高亮层）、渲染预览、选区级批注、导出、MCP。Phase B Pro AI（M7）代码已落地但**暂停验收**。

当前形态的结构性问题：**预览是只读产物，编辑必须去左侧源码栏**。

| 维度 | MDA 2.0 现状 | 竞品（WPS 365 文档） |
|------|--------------|----------------------|
| 主编辑面 | 左侧 textarea 源码 | **正文即编辑区**（所见即所得） |
| 空文档引导 | 欢迎页选文件 | 正文占位：「输入正文或 `/` 插入内容，双击 Ctrl 唤起 AI」 |
| 插入内容 | 手打 Markdown 语法 | **`/` 斜杠面板**：标题/列表/表格/代码块/公式/Mermaid/图片… |
| 选区操作 | 右键仅「添加批注」 | **选区浮动工具条**（字号/加粗/颜色/链接/列表/对齐）+ 右键菜单 |
| AI 入口 | 挂在源码栏快捷键 | **右键「AI 帮我改」**：续写/伴写/润色（多风格）/扩写/缩写/语病修正/解释/翻译/总结 |
| 复制粘贴 | 系统默认 | 复制/剪切/粘贴/**粘贴为纯文本** |

用户对「读改批注」链路的真实诉求是：**看到的就是能改的**。源码栏对轻量办公用户是门槛，对重度用户仍需保留。故 3.0 做**双模式**：预览直接编辑为主，源码编辑为辅。

### 目标

1. **体验目标**：预览区成为**主编辑面**（WYSIWYG）；原编辑栏升级为显式「源码模式」，二者共享同一份文档真源。
2. **交互目标**：对标竞品截图的四件套 —— 正文占位引导、`/` 插入面板、选区浮动工具条、右键菜单（含 AI 子菜单）。
3. **差异化目标**：批注仍是 MDA 差异化核心 —— **新预览编辑区内批注不可见**，`@anno` 语法与源文件保护不变。
4. **Pro 目标**：M7 已实现的 Provider / License / 门禁**复用**，AI 入口迁移到新编辑面的右键与浮动条（Free 见升级提示）。
5. **工程目标**：1.0/2.0 硬约束（源文件保护、批注不可见性、CLI stdout 纯净、core 分层纯净）**不得削弱**。

### 成功指标（可核验）

| 维度 | 指标 |
|------|------|
| 直接编辑 | 在预览区可完成「打字、标题、列表、加粗、链接、表格、代码块」全部编辑，**全程不暴露 Markdown 语法**（D15），无需切到源码栏 |
| 往返保真 | **路线甲**：打开 → 不编辑 → 保存，磁盘与打开前一致（AC-10）；编辑后仅改动处 diff（AC-7）。**路线乙**：`MD → 模型 → MD` 对白名单语法子集逐字符一致 |
| 批注不可见 | 预览编辑区 DOM 与导出 HTML 中 `@anno` 及任一批注字段值**零出现**（≥3 断言） |
| 源文件安全 | 批注增删改后正文逐字节不变（`verifySourceProtection` 通过）；正文编辑走 `writeRawFile` 原子写入并保留 EOL |
| 模式一致 | 预览编辑 ↔ 源码模式任意切换 5 次，内容与光标所在段落不丢失、不重复（AC-12：首可见行偏差 ≤5 行） |
| 性能 | 10 万字符文档连续输入，单次按键到屏幕更新 P95 ≤ 80ms，无光标跳动 |
| 新建体验 | 新建文档 3 次点击内可从模板开始写（内置模板 ≥ 15 项，含 README / AGENTS.md / 需求 / 架构设计 / 详细设计） |
| AI 门禁一致 | 四处 AI 入口（右键 / 浮动条 / 编辑栏 / 快捷键）在 Free 下行为一致：可见、提示升级、零网络请求 |
| 质量 | `npm test` 全通过；覆盖率不低于当前基线（Statements ≥ 88%）；新增**往返保真**与最小 diff 测试（路线甲：不建独立序列化引擎单测层） |

### F10 — 预览直接编辑（WYSIWYG）

| 编号 | 能力 | 说明 | 优先级 |
|------|------|------|--------|
| F10-1 | 双模式与单一真源 | 「预览编辑」/「源码编辑」**互斥切换**（D1）；文档真源唯一（磁盘 `.md` + 内存 Markdown 字符串），任一模式的修改都归一到该字符串 | 必做 |
| F10-2 | 行内编辑 | 打字、退格、回车分段、选择、拖选；粗体 / 斜体 / 删除线 / 行内代码 / 链接 | 必做 |
| F10-3 | 块级编辑 | 段落 ↔ 标题 H1–H6、无序 / 有序列表、任务列表、引用、分隔线、代码围栏 | 必做 |
| F10-4 | 表格编辑 | GFM 表格：单元格输入、增删行列、对齐（不做合并单元格） | 必做 |
| F10-5 | 富块「占位 + 源码微编辑」 | Mermaid / KaTeX 块（D4）：预览内作为**整体可选块**（可选中、删除、拖动位置），双击进入**该块的源码小编辑器**，不做 SVG 直接编辑；微编辑可取消（取消后源码不变） | 必做 |
| F10-6 | 图片块 | 插入 / 删除 / 替换 / alt 文本；显示宽度沿用 2.0 会话态（不写回 Markdown）。**交互（D14）**：单击选中（蓝框 + 四角手柄 + 浮动条）；拖拽手柄缩放；双击块体进入全屏预览（同 2.0 zoom overlay） | 必做 |
| F10-7 | 写回与往返保真 | **路线甲（P1 已选）**：保存 = `doc.toString()` → `writeRawFile`；装饰层不改 `doc`；**无**独立「文档模型 → Markdown」序列化步骤；合规性由 AC-10（不编辑零 diff）与 AC-7（编辑最小 diff）验收。**路线乙**：须实现 doc→MD 序列化，稳定、幂等、可预测 | 必做 |
| F10-7a | 写回粒度（D3） | 见裁决 D3 与「写回语义」表。**路线甲**：transaction 局部文本修改即满足，**禁止**为实现本项额外开发块映射写回或序列化 diff 算法。**路线乙**：默认仅改动块局部重写；全文规范化为设置项，默认关 | 必做 |
| F10-7b | 格式化整篇（D8） | 菜单中的**手动一次性动作**：执行前弹框说明「将重排全文格式，可能产生大量 diff」并需确认；执行后**可一次撤销**。**行为级要求**：撤销须将文档恢复到格式化前**最后一个字符的精确状态**（逐字节一致），**不要求**用户经历逐步回退中间态；验收仅比对撤销后全文是否与格式化前一致（见 AC-28）。实现优先编辑器单次 transaction；不支持则自动采用「格式化前内存快照、撤销整篇回填」。不自动触发、不在保存时触发 | 必做 |
| F10-8 | 撤销 / 重做 | 编辑面内 `Ctrl+Z` / `Ctrl+Y`，与源码模式切换后互不污染 | 必做 |
| F10-9 | 剪贴板 | 复制 / 剪切 / 粘贴 / **粘贴为纯文本**（`Ctrl+Shift+V`）；粘贴 HTML 时按**最小白名单**（见 F10-9 附表）转 Markdown，剥离禁止标签与属性 | 必做 |
| F10-10 | 未支持语法保护 | 3.0 白名单外的语法（HTML 内联块、脚注、front matter 等）在预览编辑区显示为**只读原文块**，禁止编辑但不得丢失 | 必做 |

**F10-9 附表 · 粘贴 HTML 最小白名单**（P0 测试基准；P2 可扩展但不得弱于本表）：

| 类别 | 允许的标签 / 结构 | 禁止 |
|------|-------------------|------|
| 文本格式 | `b`, `strong`, `i`, `em`, `u`, `s`, `del`, `code`, `pre` | — |
| 链接 | `a[href]`（仅 `href`；`title` 可选） | `javascript:` 等危险协议 |
| 列表 | `ul`, `ol`, `li` | — |
| 表格 | `table`, `thead`, `tbody`, `tr`, `th`, `td` | `colspan`/`rowspan`（3.0 不支持合并） |
| 块与换行 | `p`, `div`, `br`, `h1`–`h6`, `blockquote` | — |
| 全局禁止 | — | `script`, `style`, `iframe`, `object`, `embed`, `form`, `input` 及一切**事件属性**（`onclick` 等）、**`class` / `id` / `style` 属性**（剥离后转 MD，不保留） |

## 验收标准（Given/When/Then）

- **AC-7（预览直接编辑）**：Given 已打开一个 `.md` 且处于预览编辑模式，When 在某段落中输入文字并按 `Ctrl+S`，Then 磁盘文件对应段落更新，其余行逐字节不变，换行风格（CRLF/LF）保持原样。
- **AC-8（`/` 插入面板）**：Given 光标位于空行，When 输入 `/`，Then 浮出分组插入面板；选择「表格」后插入一个 GFM 表格且光标落在首个单元格；按 `Esc` 面板关闭且 `/` 字符不残留。
- **AC-9（选区浮动工具条）**：Given 在预览编辑区选中一段文字，When 浮动条出现并点击「加粗」，Then 选区变粗体、序列化为 `**…**`，且选区保持；点击「添加批注」进入批注流程。
- **AC-10（往返保真 · 原「序列化幂等」）**：Given 一个已按 3.0 白名单语法规范化的 `.md` 文档，When 进入预览编辑模式后**不做任何修改**再保存，Then **磁盘内容与打开时一致**（路线甲下即 `doc.toString()` 恒等，无序列化步骤）。**验收口径**：Markdown 语法节点不得被加载/保存静默改写；行尾空格允许保留或统一去除（仅此一类 diff 可接受）；EOL 由 `detectEol` 保留；不得改动 front matter / 批注行位置。
- **AC-11（批注不可见性）**：Given 文档含 `[comment]: <> (@anno {...})` 批注行，When 在预览编辑模式查看/导出 HTML，Then ①DOM 中不含 `@anno`；②不含任何批注字段值（content/tags/id）；③去掉批注行后的渲染结果与含批注时**等价**。
- **AC-12（模式切换保真）**：Given 在预览编辑区有未保存修改且光标位于某逻辑段落，When 切到源码模式再切回，Then 内容一致、脏标记保持、无重复或丢失段落。**可视状态**：首可见行（viewport 顶部对应源码行）与切换前偏差 **≤5 行**；不得重置到文首。**光标落点**：应落在切换前相同逻辑段落内（段被删则最近相邻段）；无法精确还原选区时至少落回该段首行（不得跳到文档首尾）。
- **AC-13（AI 帮我改 · Pro 门禁）**：Given 未激活 Pro，When 右键选择「AI 帮我改 → 润色」，Then 显示升级提示且不发起请求、不泄漏 Key；Given 已激活且已配 Key，Then 展示原文 vs 建议并提供**保留 / 采纳 / 取消**三选一。
- **AC-14（选区批注仍可用）**：Given 在预览编辑区选中一句话，When 添加选区批注，Then 批注写入 `@anno` 行、anchor 的 quote 与源码切片匹配、正文逐字节不变。
- **AC-15（富块保护）**：Given 文档含 Mermaid 与 KaTeX 块，When 在预览编辑区上下移动光标并在其相邻段落输入，Then 富块渲染不被破坏。**Mermaid**：单击选中（D14）；双击块体进入全屏缩放预览（非源码微编辑）；源码微编辑经顶栏「代码」并可取消。**KaTeX**：双击块进入源码微编辑并可取消。
- **AC-35（图片 / 流程图选中与全屏 · D14）**：Given 文档含图片或 Mermaid 块，When **单击**块体，Then 出现蓝色选中框、四角缩放手柄与浮动工具条（参照 `competitor-product/image-block-selected.png`），且**不**进入全屏。When 拖拽角点，Then 仅会话显示宽度变化、Markdown 源不变。When **双击**块体（非手柄），Then 打开与 2.0 相同的全屏缩放遮罩（滚轮缩放、拖拽平移、复制、Esc 关闭）。When **双击**缩放手柄，Then 还原为当前设置的默认比例（M6b-4）。Given 2.0 用户习惯单击进全屏，Then 3.0 须以文档/帮助说明「改为双击」。
- **AC-16（未支持语法保护）**：Given 文档含 3.0 白名单外语法（如内联 HTML 块），When 在预览编辑模式编辑其他段落并保存，Then 该语法原文逐字节保留，且 UI 明确提示「需到源码模式编辑」。
- **AC-17（撤销与剪贴板）**：Given 在预览编辑区做了 3 次编辑，When 连按 `Ctrl+Z`，Then 逐步回退；When 用 `Ctrl+Shift+V` 粘贴富文本，Then 仅插入纯文本。
- **AC-17b（粘贴 HTML 转 Markdown）**：Given 剪贴板含 F10-9 白名单内 HTML（如 `<b>text</b>`、`<a href="https://x">link</a>`、`<table><tr><td>a</td></tr></table>`），When 在预览编辑区 `Ctrl+V` 正常粘贴，Then 插入内容为对应 Markdown 语法，**无任何 HTML 标签残留**。Given 剪贴板含禁止项（如 `<script>`、`onclick=`、`style=`、`class=`），When 粘贴，Then 危险标签与属性被剥离，不执行脚本。Given `<h2>Title</h2>`，When 粘贴，Then 转为 `## Title` 或等价标题语法。
- **AC-18（最小写回粒度 · D3）**：**路线甲**：Given 含 20 个块的文档，When 只编辑第 3 个块并保存，Then 除用户改动触及的行外**所有行逐字节不变**——与 AC-7 同口径，**不验收**块映射或序列化实现。**路线乙**：Given「全文风格规范化」关闭，When 只编辑第 3 个块并保存，Then 除第 3 个块对应行范围外所有行逐字节不变（含空行、列表符号、表格对齐）。
- **AC-19（脏状态批注 · 先保存后写）**：Given 预览编辑区有未保存修改，When 添加一条批注，Then 先自动保存正文（原子写入 + 保留 EOL），再写入 `@anno` 行且 `verifySourceProtection` 通过；若自动保存失败，Then 中止批注操作并提示，磁盘文件不变。Given 连续添加多条批注，When 第一条触发的自动保存尚未完成，Then 后续批注**排队等待**，**不得并发启动第二次** `writeRawFile`；同批次内保存成功仅 toast 一次。Given 排队期间自动保存失败，Then **清空等待队列**、中止后续批注并提示用户。
- **AC-20（模式切换入口）**：Given 处于预览编辑模式，When 通过工具栏按钮 / 视图菜单 / 快捷键切换，Then 进入源码模式且当前模式在 UI 上可见；界面语言切换为 English 后上述文案全部为英文。
- **AC-21（常驻编辑栏与格式控件同步）**：Given 处于预览编辑模式且光标在某段落，When 点击编辑栏「H2」，Then 该段落变为二级标题并序列化为 `## `，且**顶部段落级别下拉框显示 H2**。Given 光标在正文段落，When 通过浮动工具条（F11-3）将段落改为 H3，Then **常驻编辑栏段落级别下拉框同步显示 H3**；反向亦然（编辑栏改级别 → 浮动条反映同一状态）。When 切到源码模式，Then 编辑栏切换为源码按钮集且不再显示富文本格式按钮。
- **AC-22（新建文档空态）**：Given 通过「新建」创建了未落盘文档，When 界面呈现，Then 正文显示占位引导与「从模板开始 / AI 帮我写 / 打开已有文件」三入口；When 输入任意字符，Then 引导消失且文档标记 dirty；When 按 `Ctrl+S`，Then 走另存为流程。
- **AC-23（模板套用）**：Given 在新建文档中选择「AGENTS.md」模板，When 确认，Then 整篇被模板内容替换、文档 dirty、光标落在首个可编辑位置；Given 已有文档中经 `/` 面板插入同一模板，Then 内容作为片段插入光标所在块之后，原有内容不丢失。
- **AC-24（自定义模板目录）**：Given 用户在设置中指定了本地模板目录且目录内有 `x.md`，When 打开模板列表，Then 出现名为 `x` 的模板；When 目录不存在或不可读，Then 提示错误（含「请检查设置中的模板目录路径是否正确」）且不影响内置模板可用；设置页须展示当前已配置路径的只读状态，便于用户修正误配。
- **AC-25（已有文档打开即可编辑）**：Given 打开一个含表格、代码块、Mermaid、批注的已有文档，When 界面加载完成，Then 默认处于预览编辑模式、可直接输入，批注面板与色条正常显示，正文中不出现 `@anno`。
- **AC-26（不支持语法出口）**：Given 文档含内联 HTML 块，When 在预览编辑模式查看，Then 该块标记为只读并提供「到源码模式编辑」入口；When 编辑其他段落并保存，Then 该 HTML 块逐字节不变。
- **AC-27（只读 / 超大文件降级）**：Given 打开一个无写权限或超过阈值的文件，When 加载完成，Then 自动降级为源码模式 / 只读预览并明确提示原因，且不出现可编辑但保存失败的状态。
- **AC-28（格式化整篇 · 确认与撤销）**：Given 已打开文档且记下格式化前全文快照，When 触发「格式化整篇」并确认，Then 全文重排且文档 dirty；When 按一次 `Ctrl+Z`（或点提示中的「撤销」），Then **文档内容逐字节恢复为格式化前快照**（**行为级验收**：只比对撤销后全文，不要求撤销过程为单步或多步）。**撤销不保证**光标位置、选区与滚动位置还原。Given 在弹框中取消，Then 文档零改动。若 P1 选型 undo 栈无法将全文重排合并为一次可撤销单元，则**必须**采用「格式化前内存快照、撤销整篇回填」，且脏标记与保存状态须与快照一致。
- **AC-29（AI 总结侧栏 · Pro 门禁）**：Given 未激活 Pro，When 点击侧栏「要点」tab，Then 显示升级提示且不发起网络请求；Given 已激活并配置 Key，When 生成总结，Then 流式呈现、可取消、结果**不写入文档**，点击「插入到文档」后才写入并标记 dirty。
- **AC-30（AI 全线 Pro 门禁一致）**：Given 未激活 Pro，When 依次从右键菜单、浮动条、编辑栏 AI ▾、快捷键触发任一 AI 动作（含伴写 / 解释），Then 四处行为一致：均显示升级提示、均不发起请求、均不泄漏 Key。
- **AC-31（获取模型列表）**：Given 已激活 Pro 且已配置有效 API Key 与 Base URL，When 在设置中点击「获取模型列表」，Then 从 `GET /v1/models`（或等价端点）拉取并合并入模型列表，列表中出现至少一个 model id，且不重复添加已有项。Given Key 无效或网络失败，Then 提示脱敏错误且列表不被清空。
- **AC-32（手动添加模型）**：Given 模型列表中尚无 `my-custom-model`，When 用户通过「添加模型」输入该 id 并确认，Then 列表出现该项且默认**启用**；When 再次添加同一 id，Then 提示已存在且不重复。
- **AC-33（模型启用 / 停用）**：Given 列表含模型 A（启用、默认）与模型 B（启用），When 停用模型 A，Then A 不可被选为默认且 AI 请求改用 B（或提示用户重选默认）；When 停用全部模型，Then 触发 AI 动作时提示「请先在设置中启用至少一个模型」且不发起请求。
- **AC-34（检测可用性）**：Given 已配置 Key、Base URL 与默认模型，When 点击「检测」，Then 在 **15 秒内**返回成功或失败结果（toast 或行内状态）；成功时不泄漏 Key；失败时提示可读原因（如 401 / 模型不存在 / 超时）且不含 Key 片段。Given Provider 级开关为停用，When 点击检测，Then 提示 Provider 已停用且不发起请求（或检测前要求先启用，P2 定一种一致行为）。

## 非功能需求

> **编号说明**：NF-1~NF-9 继承 MDA 2.0 非功能需求（见 [`P0-requirements-v2-commercial.md`](P0-requirements-v2-commercial.md)），本表从 NF-10 起续增。

| 编号 | 类别 | 描述 |
|------|------|------|
| NF-10 | 性能 | 10 万字符文档：按键到屏幕 P95 ≤ 80ms；不得因每次输入全量重渲导致光标跳动 |
| NF-11 | 数据安全 | 编辑不得静默丢内容；写回/序列化异常必须**阻止保存并提示**，绝不写入残缺文档 |
| NF-12 | 兼容性 | 保留 BOM 与 EOL 风格；未支持语法原样保留；`@anno` 行位置与内容不被正文编辑逻辑改写 |
| NF-13 | 可用性 | 全键盘可达：`/` 面板、浮动条、右键菜单均可键盘操作；Esc 一致关闭 |
| NF-14 | i18n | 所有新增用户可见文案经 `t` / `uiT` / `MDAI18n`，zh + en 同时落地 |
| NF-15 | 安全 | 保持 `contextIsolation: true`、`nodeIntegration: false`；粘贴 HTML 须按 F10-9 最小白名单净化，禁止执行脚本；不得向渲染层暴露 `fs` |
| NF-16 | 离线 | 除 Pro AI 请求外全部功能离线可用；新增依赖须可离线打包 |
| NF-17 | 可测试性 | **路线甲**：装饰规则、写回边界、批注共存等须可单测的纯函数层（不依赖 Electron/DOM 的部分尽量下沉）；**不要求**独立序列化引擎单测。**路线乙**：序列化层须可单测 |
| NF-18 | 包体 | 新增依赖后安装包增量 ≤ 15MB（P1 选型时核算） |
| NF-19 | 模板 IO 安全 | 自定义模板目录的读取只在主进程进行、仅读 `.md`、路径校验后经 IPC 返回；模板内容按普通 Markdown 净化渲染，不执行任何脚本 |
| NF-20 | 优雅降级 | 未激活 Pro 或无网络时，模板库、编辑栏、`/` 面板、批注等非 AI 功能必须完全可用；AI 区域只显示提示不阻塞编辑 |
| NF-21 | AI 长文分段 | F17 总结须按标题树分段：H1/H2 优先，单段 ≤3000 token（或模型上限 80%），超限下钻 H3；分段策略在 P2 细化但不得弱于本下限 |
| NF-22 | AI 模型列表请求 | `GET /v1/models` 与「检测」请求超时默认 **15s**；检测与获取列表**互斥**（进行中禁用按钮）；并发检测请求 ≤1；错误信息脱敏（NF-15 延续） |

## 接口契约

### 不变更

| 条目 | 说明 |
|------|------|
| 批注语法与正则 | `[comment]: <> (@anno {JSON})` 与 `ANNO_REGEX` 保持不变 |
| 源文件保护 | 批注写操作只增删改 `@anno` 行，`verifySourceProtection` 必过 |
| 原子写入 | 临时文件 + `fs.rename`；`detectEol` 保留换行风格 |
| core 分层纯净 | `src/core` 不依赖 GUI；`renderer.ts` 不得注入 `data-line` |
| CLI / MCP 契约 | `mda-cli` 四命令与 MCP 六 tools 语义与输出规范不变；stdout 仅数据 |
| 程序命名 | GUI = `mda`，CLI = `mda-cli`，MCP = `mda-mcp` |
| GUI 弹窗规范 | 禁用原生 `alert/confirm/prompt`，统一 `uiAlert`/`uiConfirm` |

### 允许变更

| 条目 | 范围 |
|------|------|
| GUI renderer 结构 | 新增 WYSIWYG 编辑面模块、`/` 面板、浮动条、右键菜单；预览容器职责重构 |
| preload 桥 | 新增编辑相关 API（保存、批注、模板等；仍不暴露 `fs`）。**路线甲**无需暴露序列化 API |
| `data-line` 用途 | 批注色条与段落定位；**路线甲**不扩展为块写回映射 |
| 快捷键分配 | 可重新分配（须在帮助与 i18n 同步）；`Ctrl+B` 等在编辑面语义可调整 |
| 新依赖 | 允许引入编辑器 / 序列化依赖（P1 选型，须满足 NF-16/NF-18） |
| 布局与菜单 | 模式切换入口、菜单项、设置项可调整 |

## 风险与不确定性

| 风险 | 影响 | 缓解 |
