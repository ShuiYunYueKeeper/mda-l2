# P0–P4 工作流速查

> 完整版见已初始化项目中的 `.cursor/workflow.md`。
> 适用于任意软件工程任务，不限于命题式考核。

## 项目适配层（接入时先填）

工作流只规定「做什么、在哪设门禁」。在 `AGENTS.md` 声明本项目的等价命令：
构建 / 静态检查 / 单元测试 / 集成端到端 / 人工实机验证 / 交付物校验 / 不变量校验。
标「不适用」的动作可跳过，但不得顺带跳过同层级的其他校验。

## 任务分档（决定跑几个阶段）

| 档位 | 触发判据 | 跑哪些阶段 | 最小产出 |
|------|---------|-----------|---------|
| T0 微改 | 单文件、无行为变化 | P4 | 规范 commit message |
| T1 缺陷修复 | 现象明确、不改公共接口 | P4（+根因说明） | 根因 + 修复 + 回归用例 |
| T2 小增强 | 单模块、接口兼容 | P0 精简 + P2 精简 + P4 | 一份合并设计文档 |
| T3 模块级特性 | 跨 ≥2 模块或新公共接口 | P0–P4 完整 | 四份阶段文档 |
| T4 子系统 / 迁移 | 新进程 / 新依赖 / 数据格式变更 / 不可逆 | P0–P4 + 里程碑 | 四份文档 + 验收清单 |
| T5 探索原型 | 需求或可行性未知 | 问题陈述 + POC | POC 结论报告（不并入主干） |

档位**只升不降**，不确定时就高不就低；T5 有结论后回到 T2/T3/T4 重新定档。

## 阶段门

每阶段产出须 **用户确认** 后才能 commit 并进入下一阶段。
各阶段模板自带「退出门禁」，未全部满足不得进入下一阶段。

## P0 自查要点

- 每条 FR 至少对应一条 AC；AC 必须 Given/When/Then 且标注验证层级
- 明确写出「非目标」与「不得破坏的既有行为」
- 非功能需求可量化 + 有验证方式
- 假设标注 ✅/❓/⚠️，❓ 假设在开放问题中有责任人
- 对抗自检 4 问；无 TODO/TBD/占位符

## P1 自查要点（架构设计）

- 方案对比 ≥2（T4 ≥3），被否决方案须写否决理由
- 质量属性驱动因素 → 达成机制 → 验证方式，三者成链
- 依赖方向明确、无循环依赖
- 新引入依赖评估许可证与退出成本
- Mermaid ≤12 节点；预死亡 ≥3；对抗审查 5 问
- 综合置信度 ≥80% 或已完成补强（POC / 补证据）

## P2 自查要点（详细设计）

- **伪代码可被直接翻译为代码**，无「省略细节」类表述
- 接口有完整签名 + 前置/后置条件 + 错误定义 + 幂等性
- 边界用例 E 表覆盖 P0 全部 E 编号并按维度补齐（空 / 超长 / 编码 / 并发 / 中断 / 权限 / 极端规模）
- 每条 AC 在测试设计矩阵中至少出现一次；只能人工验证的项须写明原因
- 错误处理有降级策略与「绝不允许发生」的底线
- 并发 / 原子性 / 幂等已明确或明确写「不涉及」

## P3 自查要点（实施计划）

- **每个任务都有输入 / 输出 / 可判定的验收（引用 AC-n、E-n）**
- 任务粒度可一次专注完成；DAG 无环；并行任务不写同一文件
- 标注执行主体（AI 主导 / 人工主导 / 人工确认），人工配合项单列
- 验证矩阵覆盖全部 AC 与 E，缺口须说明
- 预死亡 ≥3 条含检测方式与回滚；回滚策略可直接执行

## P4 硬原则

1. 先编译，再测试
2. 核心先行，适配层/UI 后置
3. 测试失败当场修复
4. UI 改动：build 通过 ≠ 验证完成，须用户实机确认
5. 核心逻辑变更同步 `tests/` 与 `AGENTS.md`

## 推理侧工程组合（每步用什么手段）

| Step | 必用 |
|------|------|
| 1 审查 | RAG 检索链（`AGENTS.md` 索引 → `docs/` → 全仓检索）；`git status` |
| 2 实施 | 少样本对照隐性规范与 few-shot；非平凡改动先出方案 |
| 3 自查 | 思维链复核算法；静态检查；`git diff` 只改预期文件 |
| 4 验证 | 输出校验三层（结构/类型 · 语义不变量 · 行为）+ 对抗自检 + UI 实机 |
| 5 文档 | 反思沉淀到 `AGENTS.md` / few-shot / `docs/prompts/` |

硬性约束：不以记忆代替检索；不以「全绿」代替实机；不并行写同一文件；
结论改口须附工具证据；投票不替代根因定位；每轮踩坑必沉淀。
